# プロジェクト WBS

目的: フロントエンド、バックエンド・インフラ・QA・ドキュメント・リリースまでの全タスクを網羅的に分解する。

前提: バックエンドは REST API で実装され、フロントは Vite + React + TypeScript + Tailwind を使用。
